# CCW 扩展审核说明

## 扩展用途

本扩展仅作为 HTML5 游戏显示容器。创作者的游戏逻辑、角色、战斗、数据和
存档均位于其独立网页游戏中，本扩展不重新实现这些系统。

## 需要审核版权限的原因

扩展需要读取 `runtime.renderer.canvas` 的显示位置，并在同一页面中创建
iframe 覆盖舞台画布。普通沙箱远程扩展不能访问舞台 DOM，因此本功能只能
作为 CCW 审核扩展发布。

## 安全措施

- 发布环境仅接受 HTTPS 地址；HTTP 只允许 localhost 本地测试。
- 不使用 `eval`、`new Function` 或动态脚本注入。
- iframe 不允许弹出窗口或顶层页面跳转。
- 不读取 iframe 内部 DOM，不绕过浏览器同源策略。
- 不采集、不保存、不上传鼠标、键盘或游戏数据。
- 不访问 Scratch 变量、列表、角色或云数据。
- 点击停止、执行“关闭游戏”或卸载扩展时销毁 iframe。
- iframe 被限制在舞台画布的可见矩形内。

## 审核测试步骤

1. 添加扩展并执行 `加载游戏 [demo/index.html]`。
2. 确认演示页面只覆盖 16:9 舞台，不覆盖编辑器其他区域。
3. 在演示页面点击，确认鼠标计数增加。
4. 按任意键，确认页面显示对应按键。
5. 确认页面 JavaScript 正常执行。
6. 执行 `调整显示大小 宽度 [1280] 高度 [720]`，确认保持 16:9。
7. 改变窗口尺寸并进入/退出全屏，确认容器持续贴合舞台。
8. 执行 `关闭游戏`，确认 iframe 消失。
9. 重新加载游戏后点击停止按钮，确认 iframe 和音频均停止。
