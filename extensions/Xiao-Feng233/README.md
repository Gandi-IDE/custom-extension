# 增强音乐（Enhanced Music）

采样级音乐演奏扩展：用采样音色演奏旋律与鼓组，支持 MIDI 力度（0-127）、延音踏板、脚本级音量与多段广播结构。

- 入口文件：`enhanced-music.js`（id: `enhancedMusic`）
- 内置 15 个钢琴采样（MIDI 24-108，base64 内嵌），加载即弹
- 作者：Xiao-Feng233
- TurboWarp 版主页（含作品示例）：https://github.com/Xiao-Feng233/TurboWarp-Music-Enhanced
